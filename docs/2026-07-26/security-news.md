# セキュリティーニュース

更新日時: 2026-07-26 08:31:36 JST

SecurityWeek、Krebs on Security、BleepingComputer、The Record、Dark ReadingのRSSから、JST基準で本日公開されたセキュリティ関連記事を収集しています。

## 今日の総括

ゲーム関連フォーラムや偽サイトを利用したマルウェア感染が増加しています。特に暗号通貨マイナーの不正インストールやブラウザメモリ上でのマルウェア構築が確認されています。これらの攻撃はユーザーの端末を直接狙い、被害拡大のリスクが高まっています。

## [Steam forum ClickFix attacks infect gamers with XMRig cryptominers](https://www.bleepingcomputer.com/news/security/steam-forum-clickfix-attacks-infect-gamers-with-xmrig-cryptominers/)

- 重要度: **HIGH**
- メディア: BleepingComputer
- 公開日時: 2026-07-26 07:37 JST
- 要約: SteamフォーラムでゲームやPCの問題を修正すると偽り、XMRig暗号通貨マイナーを感染させるClickFix攻撃が発生しています。ゲーマーの端末が不正にマイニングに利用される危険があります。

## [Malicious sites use JavaScript to build malware in browser memory](https://www.bleepingcomputer.com/news/security/malicious-sites-use-javascript-to-build-malware-in-browser-memory/)

- 重要度: **HIGH**
- メディア: BleepingComputer
- 公開日時: 2026-07-26 00:21 JST
- 要約: 偽のSolana、Luno、TradingViewサイトで悪意あるJavaScriptが実行され、ブラウザのメモリ上でマルウェアを組み立てる大規模なマルバタイジングキャンペーンが確認されました。直接的なマルウェア感染手法として注目されます。
